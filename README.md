# Мониторинг опросов — публичная страница

**[Свод прохождения опросов](https://adelinaatp-source.github.io/opros/)** (`index.html`) —
вторая волна: Telegram-бот доопроса. Сколько сотрудников прошли опрос и сколько сессий
проведено, в разрезе управлений и крупных подразделений.

## Персональных данных здесь нет

Страница публичная (доступна по ссылке), поэтому содержит **только агрегаты**: итоги, проценты
и разрезы по управлениям и по подразделениям, где работает **5 и более человек**. Подразделения
меньшего размера объединены в «Прочие подразделения».

**Что сюда не попадает никогда:** ФИО, должности, строки по отдельным сотрудникам, отметки
времени последней активности.

Детальная доска «кто сколько прошёл» с фамилиями ведётся в приватной базе знаний и
предоставляется руководству отдельным документом.

## Как обновить

Страница **не редактируется руками** — её собирает скрипт из приватных исходников:

```
python knowledge-base/_scripts/svod-anon-build.py wave2
```

Автообновление (Планировщик Windows, задача `opros-autoupdate`) делает то же самое каждые
30 минут в рабочее время: пересчитывает результаты бота, обновляет детальный свод в базе
знаний и публикует сюда **только обезличенные агрегаты**. Перед публикацией результат
автоматически проверяется на персональные данные; если что-то просочилось — публикация
не выполняется.

`.gitignore` устроен по принципу «запрещено всё, разрешено поимённо».

> Внутренний ресурс ООО «СКС Ломбард». Ссылка публичная, из поисковой выдачи скрыта (`noindex`).
