# Q: Как показать имя исходного файла для каждой сессии опроса?

## Answer

Session уже содержит source_file, но person_payload не переносил его в data/details.json. Поле source_file добавлено в detail_sessions, интерфейс showPerson выводит безопасное базовое имя файла, а валидатор требует непустое поле у каждой сессии. После пересчёта имя присутствует у 1042 из 1042 сессий.
